#### P4-02 图片导出功能（必选）
- **必选组件**: 导出按钮、html-to-image 脚本、导出逻辑代码
- **功能规范**:
  - **按钮位置**：海报容器外部，固定定位，不遮挡海报内容
  - **按钮样式**：与海报风格协调，醒目易点击
  - **导出库**：使用 html-to-image（从 CDN 加载，带 unpkg 回退），基于 SVG foreignObject + 浏览器原生渲染引擎，导出与页面 1:1 一致
  - **导出参数**：
    - `pixelRatio: 3`（固定 3 倍分辨率，确保所有设备一致）
    - `cacheBust: true`（禁用缓存避免旧资源）
    - `backgroundColor: '#ffffff'`（白色背景兜底）
  - **字体等待**：导出前通过 `document.fonts.ready` 等待字体加载完成，延迟 200ms 确保渲染完毕
  - **导出范围**：截取 `.poster` 元素完整区域
  - **文件命名**：与 HTML 文件同名，扩展名改为 `.png`
  - **导出后行为**：自动触发下载，无需额外操作
- **可选组件**: 导出进度提示、导出格式选择（PNG/JPEG）
- **组装顺序**: html-to-image CDN 引入→导出按钮 HTML→导出按钮 CSS→导出逻辑 JS
- **约束**: 导出功能必须零配置可用；CDN 地址必须使用稳定版本；导出按钮不得影响海报布局；**文字渐变效果必须使用 SVG `<text>` + `<linearGradient>` 实现，禁止使用 CSS `background-clip: text` 实现渐变文字**（后者在 html-to-image 导出时会导致渐变背景丢失，文字变为纯色或透明）；**禁止使用 html2canvas**（其在 canvas 2D 上下文中重新实现 CSS 渲染，与浏览器原生排版引擎存在差异，导致背景色/透明度/渐变/阴影等导出不一致）
- **格式**: 嵌入 HTML 的 `<script>` 和 `<style>` 代码

#### P4-02-CSS 导出兼容规范（必选）

导出图片时部分 CSS 属性在 DOM 序列化过程中会丢失或变形，必须在生成阶段就避免使用，改用导出兼容的替代方案：

| 禁止使用的 CSS | 导出问题 | 替代方案 |
|---------------|---------|---------|
| `background-clip: text` + `-webkit-text-fill-color: transparent` | 渐变文字背景丢失，文字变透明或纯色 | SVG `<text>` + `<linearGradient>` |
| `opacity`（作用于容器） | 子元素透明度叠加异常，与页面显示不一致 | 用 `rgba()` 设置颜色透明度 |
| `backdrop-filter` | 毛玻璃效果丢失，背景变纯色 | 用半透明背景色 `rgba()` 模拟 |
| `mix-blend-mode` | 混合模式丢失，颜色不一致 | 避免使用，改用具体颜色值 |
| `filter: blur()`（大半径） | 模糊范围可能不一致 | 用 SVG `<feGaussianBlur>` 或预设模糊背景图 |
| `background-image: url(data:...)`（超大 base64） | 序列化时可能截断导致背景丢失 | 拆分为多个小图或用 SVG 内联绘制 |
| `position: sticky` | 粘性定位在序列化时退化为静态 | 改用 `position: relative` 或 `fixed` |
| `css var()` 引用未定义变量 | 变量值为空，属性丢失 | 确保所有 `--xxx` 变量在 `:root` 有默认值 |
| `box-shadow`（多层且含 inset） | inset 阴影可能丢失 | 简化为单层外阴影，inset 用 border 模拟 |

**通用导出兼容原则**：
1. **背景色必须显式设置**：所有容器必须设置明确的 `background` 或 `background-color`，不依赖父级继承，避免导出时背景透明
2. **透明度用 rgba 而非 opacity**：需要半透明效果时用 `rgba(r,g,b,a)` 设置颜色，不用 `opacity` 属性
3. **渐变用 SVG 而非 CSS**：文字渐变用 SVG `<text>`，背景渐变可用 CSS `linear-gradient`（html-to-image 对背景渐变支持良好）
4. **避免空变量引用**：所有 `var(--xxx)` 必须在 `:root` 中有对应定义
5. **阴影保持简单**：最多 2 层外阴影，避免 inset 阴影

#### P4-02-SVG 渐变文字规范（导出兼容）

导出图片时 CSS `background-clip: text` 方案的渐变背景会丢失，必须改用 SVG 实现渐变文字：

- **实现方式**：使用 `<svg>` 内嵌 `<defs><linearGradient></linearGradient></defs>` + `<text fill="url(#gradId)">` 渲染渐变文字
- **禁止**：CSS `background-clip: text` + `background-image: linear-gradient(...)` + `-webkit-text-fill-color: transparent` 组合
- **原因**：html-to-image 基于 SVG foreignObject 序列化 DOM，CSS `background-clip: text` 在序列化时渐变背景无法正确传递，导致导出图片中文字渐变丢失
- **SVG 渐变文字示例**：
  ```html
  <svg width="400" height="60" viewBox="0 0 400 60">
    <defs>
      <linearGradient id="titleGrad" x1="0%" y1="0%" x2="100%" y2="0%">
        <stop offset="0%" stop-color="#00f0ff"/>
        <stop offset="100%" stop-color="#b026ff"/>
      </linearGradient>
    </defs>
    <text x="0" y="40" font-size="32" font-weight="700" fill="url(#titleGrad)">渐变标题文字</text>
  </svg>
  ```
