# 图片海报生成技能

## 定位

本技能提供从设计规范到图片海报输出的完整能力。

**输出形式**：生成各种类型的图片海报，满足不同场景需求。

## 核心能力

### 设计规范能力

内置完整的设计规范，确保生成的图片海报风格统一、专业：

- **颜色系统**：9色系×7层级的完整调色板
- **字体系统**：标题/正文/辅助文字的大小、字重、行高规范
- **布局系统**：页面尺寸、页边距、间距规范
- **样式系统**：预设样式类

### 内容生成能力

生成结构化内容，满足不同场景需求：

- **广告海报**：产品广告、品牌广告、促销广告海报
- **宣传海报**：活动宣传、品牌宣传、产品宣传海报
- **活动海报**：会议、展览、演出、赛事活动海报
- **产品海报**：产品介绍、产品特点、产品优势海报

### 模板应用能力

基于模板快速生成，保持风格一致：

- **内置模板**：常用模板
- **自定义模板**：支持用户自定义模板
- **风格继承**：从模板继承风格和格式

### 输出保存能力

支持多种输出选项，满足不同使用场景：

- **标准输出**：标准格式
- **格式保持**：保持所有格式
- **版本兼容**：支持不同版本
- **图片导出**：生成的 HTML 海报自带「导出为图片」按钮，点击即可一键导出高清 PNG，无需额外工具或命令

### 样式优化能力（协作 design-taste-frontend 技能）

在内容生成后，调用 `design-taste-frontend` 技能对海报样式进行专业级美观度优化：

- **设计度量驱动**：基于度量规则验证视觉质量，而非凭感觉调整
- **严格组件架构**：遵循专业组件设计规范，确保可维护性
- **CSS 硬件加速**：应用 transform、will-change 等优化渲染性能
- **平衡设计工程**：在视觉美感与工程性能之间取得平衡
- **无障碍访问**：确保色彩对比度与可读性符合 WCAG 标准

## 使用规则

### 执行流程

1. **首次加载**：读取 `references/poster-catalog.md`，获取设计规范和组件清单
2. **按需深入**：确认类型后，读取 `references/poster-requirements.md` 获取生成要求；如需范本，读取 `references/exemplars.md` 获取参考
3. **样式优化（关键步骤）**：在内容生成完成后，调用 `design-taste-frontend` 技能对海报的样式美观度进行专业优化，包括但不限于：
   - 视觉层次与信息架构优化
   - 间距、对齐与栅格规范校准
   - 色彩对比度与可读性提升
   - 字体层级与排版细节打磨
   - 组件样式与微交互优化
   - CSS 硬件加速与性能优化
4. **独立执行**：本技能除调用 `design-taste-frontend` 进行样式优化外，其余能力均已内嵌，可直接生成

### 输出规则

1. **文件输出**：生成的内容保存为相应格式文件
2. **软件查看**：用户可通过相应软件打开文件
3. **格式保持**：确保所有格式正确显示

## 执行框架

本技能内嵌了完整的执行框架。

**核心理念**：
- **规范驱动**：所有内容必须遵循设计规范
- **内容适配**：根据需求选择最合适的内容结构
- **用户友好**：输出文件可直接使用，无需额外处理

**统一执行流程**：收到任务后按5步执行——需求分析 → 内容规划 → 内容生成 → 样式优化 → 文件输出。

### Step 0：需求分析

分析用户的需求：
- 内容类型
- 目标受众
- 使用场景
- 保存需求

### Step 1：内容规划

根据需求分析结果规划内容：
- **结构规划**：内容结构
- **风格规划**：设计风格
- **内容规划**：具体内容

### Step 2：内容生成

根据设计规范生成内容：
- 应用颜色系统
- 应用字体系统
- 应用布局规则
- 应用样式系统

### Step 3：样式优化（调用 design-taste-frontend 技能）

将 Step 2 生成的海报 HTML 交由 `design-taste-frontend` 技能进行专业样式美观度优化：
- **视觉层次**：优化信息架构与视觉权重分布
- **间距与栅格**：校准间距、对齐与栅格规范，确保节奏感
- **色彩与对比**：提升色彩对比度与可读性，确保无障碍访问
- **字体与排版**：打磨字体层级、行高、字距等排版细节
- **组件与交互**：优化组件样式与微交互细节
- **性能优化**：应用 CSS 硬件加速与渲染性能优化
- **设计度量**：基于度量规则验证设计质量，确保符合专业标准

优化完成后，将优化后的 HTML 传递给 Step 4 进行文件输出。

### Step 4：文件输出

将优化后的内容保存为文件：
- 保存为相应格式
- 在 HTML 中嵌入「导出为图片」按钮及导出脚本（html-to-image）
- 告知用户文件位置和打开方式
- 告知用户可直接在浏览器中点击按钮导出 PNG 图片

按使用流程组织，共5域19种任务：

| 域 | 任务数 | 典型任务 |
|----|--------|---------|
| P0 需求分析域 | 4 | 海报类型识别、目标受众分析、使用场景分析、输出格式选择 |
| P1 设计规范域 | 4 | 颜色系统应用、字体系统应用、布局规则应用、样式系统应用 |
| P2 内容生成域 | 4 | 广告海报生成、宣传海报生成、活动海报生成、品牌海报生成 |

## 事实纪律

1. 设计规范必须来自 `references/poster-catalog.md`，不可凭感觉
2. 生成的内容必须符合规范要求，不可随意修改样式
3. 文件输出必须使用标准格式，确保软件兼容性
4. 复杂内容必须使用成熟的库，不可自行实现复杂逻辑
5. 格式保持功能必须使用标准API，不可依赖第三方服务
6. **文字渐变效果必须使用 SVG `<text>` + `<linearGradient>` 实现，禁止使用 CSS `background-clip: text`**（导出图片时 CSS 渐变文字会丢失背景，SVG 方案才能保证导出后渐变效果完整保留）
7. **禁止使用 html2canvas 导出**，必须使用 html-to-image（前者在 canvas 中重新实现 CSS 渲染，导致背景/透明度/渐变/阴影等与页面不一致）
8. **导出兼容 CSS 规范**：容器必须显式设置背景色（不依赖继承）；透明度用 `rgba()` 而非 `opacity`；避免 `backdrop-filter`/`mix-blend-mode`；所有 `var(--xxx)` 必须有默认值；阴影最多 2 层外阴影
