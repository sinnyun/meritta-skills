# Eval Case: Tool Skill

## 用户需求

> 创建一个人物照片背景移除 Skill

## 需求分析

- 输入：人物照片文件路径
- 输出：去背景后的 PNG 文件
- 运行环境：本地 Node.js 或 Python
- 工具依赖：图片处理库或模型 API

## 验证重点

### 应该做到的

- [ ] 正确识别需要外部工具/脚本（不是纯模型任务）
- [ ] 创建 scripts/ 目录，包含图片处理脚本
- [ ] 脚本有明确的输入输出
- [ ] 脚本包含错误处理（文件不存在、格式不支持、处理失败）
- [ ] SKILL.md 描述工具使用规则
- [ ] description 包含"抠图""背景移除"等触发词

### 不应该做的

- [ ] 不应该只用 Prompt 描述"用 AI 模型处理"而不提供具体工具
- [ ] 不应该创建不必要的 references（除非有 API 文档需要引用）
- [ ] 不应该缺少异常处理

## 评审要点

Reviewer 应该检查：
1. 是否正确识别需要 Script（而非纯 Model）
2. 脚本是否可独立运行
3. 错误处理是否完整
4. 输入输出是否明确
5. 工具依赖是否合理声明
