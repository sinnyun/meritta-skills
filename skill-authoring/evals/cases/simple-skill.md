# Eval Case: Simple Skill

## 用户需求

> 创建一个把工作记录整理成周报的 Skill

## 需求分析

- 输入：会议记录文本（语音转写、手动笔记等）
- 输出：结构化的会议纪要（结论 + 待办事项）
- 运行环境：纯模型，无外部工具
- 工具依赖：无

## 验证重点

### 应该做到的

- [ ] SKILL.md 简洁，不超过 2000 字
- [ ] 不创建 scripts/ 目录（不需要脚本）
- [ ] 不创建 references/ 目录（不需要大量知识）
- [ ] 不创建 assets/ 目录（不需要模板素材）
- [ ] description 包含"会议纪要""整理""结论""待办事项"等触发词
- [ ] Workflow 清晰：接收会议记录 → 提取关键结论 → 提取待办事项 → 格式化输出

### 不应该做的

- [ ] 不应该过度设计（创建不必要的脚本和目录）
- [ ] 不应该把简单 Prompt 包装成复杂 Skill（但也不能太简单到无法复用）
- [ ] 不应该创建 init_skill.py 之类的脚本（纯模型任务不需要）

## 评审要点

Reviewer 应该检查：
1. 是否过度设计（最大的风险）
2. Workflow 是否清晰（提取结论 vs 提取待办是否分开）
3. description 是否能准确触发（包含"会议纪要""整理""待办"等关键词）
4. Context 是否高效
