# 标杆场景提示词库（flagship prompts）

本文件是 **11 套标杆场景的生成提示词**。每段提示词是**纯需求描述**——只说明要什么（场景/视觉/功能/数据/质量），**不含任何实现细节**（不出现"复制模板""对齐模板""模板名"等字眼）。实现由 workbench-pro 技能完成：匹配场景 → 取对应模板为工作副本 → 按提示词改皮 → 冒烟交付。

## 使用方式

1. 按场景挑对应提示词，整段发给技能即可。
2. 技能内部流程（对用户透明）：匹配场景 → 复制对应模板为工作副本 → 改皮（品牌/种子数据/hero 文案/按需换色）→ 保留布局/模块/JS 引擎/双端导航 → 冒烟全绿。
3. 生成后效果必须等于同场景现有标杆，模块一个不能少。

## 提示词通用要求（每段均已内嵌）

- **场景**：明确场景与目标人群，触发技能匹配。
- **视觉**：描述想要的配色/布局/氛围，效果必须等于同场景现有标杆（不低于）。
- **功能**：列出该场景应有的完整功能（通用载体功能一个不能少：增删改查/搜索筛选/导入导出/双端导航/数据统计）。
- **双端**：PC 端有侧栏导航，移动端有底部导航。
- **数据**：真实感示例数据（含逾期/进行中/已完成），首屏不空白。
- **质量**：冒烟测试全绿。

## 提示词使用注意

1. **每段 = 一次完整调用**：整段发给技能即可，无需额外说明。
2. **提示词只描述需求**，不含"复制/对齐模板"等实现细节——实现由技能内部完成。
3. **效果验收口径**：生成后视觉/功能/模块必须等于同场景现有标杆，模块一个不能少；冒烟全绿才可作标杆展示。
4. **已知坑**：② 需按响应式铁律生成（不固定最小宽度、不残留外链）；⑧ 移动端需补底部导航。
