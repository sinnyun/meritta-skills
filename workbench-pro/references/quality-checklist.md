# 冒烟自检清单 + 代码质量标准

交付前逐条默读代码确认，有一条不过就修，修完再交付。

## A. 架构自检（最高优先级）

1. **调用链无环路**：列出所有渲染函数（renderXxx）的调用关系，确认任意两个渲染函数之间无 A→B→A 调用；所有联动都经由事件处理函数 → 改数据 → `refreshAll()`。
2. **初始化链路通畅**：从 `DOMContentLoaded` 走一遍：加载数据 → 空则种示例数据 → `refreshAll()` → 绑定事件；每个被调函数在调用点之前已定义（或为函数声明提升）。
3. **渲染函数只读数据**：每个 renderXxx 只从 state/Store 读最新数据并更新 DOM，不写数据、不触发其他渲染。

## B. DOM 与事件自检

4. **元素存在性**：所有 `getElementById`/`querySelector` 的目标在 HTML 中存在；动态渲染后重新绑定的监听器无重复绑定（用事件委托优先）。
5. **事件绑定时机**：所有 `addEventListener` 在对应 DOM 存在之后执行；动态列表用容器级事件委托，避免逐项绑定。

## C. 数据自检

6. **空数据不崩**：清空所有数据后刷新页面，各模块显示空态文案而非报错；首次打开自动种入 3-5 条示例数据（含 1 条逾期）。
7. **存储隔离**：所有 localStorage key 带 `wb_{id}_` 前缀；JSON.parse 全部有 try-catch 与默认值兜底。
8. **向后兼容**：读数据时对每个字段给默认值（旧版本数据缺字段不报错）；导入 JSON 后先做字段校验再合入。
9. **30 条备份提醒**：主数据集达到 30 条时顶部出现一次性温和提示，可关闭不再打扰。

## D. 日期与边界自检

10. **跨月/跨年**：月份切换（1月↔12月、12月31日↔1月1日）计算正确；"今天"以本地时区 `new Date()` 的 YYYY-MM-DD 为准，不用 UTC 字符串截取。
11. **逾期判定（四档互斥）**：due < 昨天 → 逾期标红；due = 昨天 且未完成 → 显示"顺延"角标（琥珀色）；due = 今天 → "今天"；今天之后三天内 → 显示日期。四档筛选条件必须互斥，严禁同一事项渲染两条（实测踩坑：overdue 用 `due < 今天` 会与顺延档重叠导致重复渲染）；完成项不再出现在今日区。

## E. 视觉与移动端自检

12. **端适配按主端（桌面优先 + 响应式）**：双视口模拟——桌面 1280px 双列网格（今日区主列 + 模块副列，无溢出）；移动 375px 自动单列堆叠、无横向溢出（除刻意横滚区）、按钮 ≥44px、输入框字号 ≥16px、底部安全区 padding 生效。
12b. **双端导航完整**：桌面 1280px 视口下必须能看到左侧 sidebar 菜单（或模板母版的导航骨架）；移动 375px 视口下必须能看到底部 Tab 导航栏（footer/tabbar）——任一端的模块导航缺失即为不合格（PC 丢 menu、移动丢 footer 均判失败）。
13. **颜色语义**：记账类支出红/收入绿；涨跌红绿遵守中国习惯；逾期红、成功绿、警告橙。
14. **零外链**：全文搜索 `http`、`cdn`、`@import`、`<link`、`<script src`——除内联外不应出现任何外部资源引用；emoji 未被当作图标使用。

## F. 代码质量标准

- 常量集中定义（APP 配置对象），无魔法字符串散落。
- 单函数 ≤40 行为宜，超出的拆为计算函数 + 渲染函数。
- 日期处理统一走 `fmtDate()` / `todayStr()` 等工具函数，禁止散落的字符串拼接。
- XSS 防御：用户输入内容插入 DOM 前经 `esc()` 转义。
- 所有弹层（确认框、抽屉）为页面内 div，不用 `alert/confirm/prompt`（清空数据等关键操作可用原生 confirm 兜底，但优先自绘弹层）。
