# 场景 × 模块矩阵

每个工作台上限 4 个模块。「今日要处理」区是骨架自带的全局模块，不计入上限。

组件代号：RING=进度环 · MATRIX=打卡矩阵 · HEAT=日历热力图 · TREND=趋势折线图 · PIE=占比环图 · SHOP=积分商城 · FLIP=翻卡学习卡

| 场景 | 目标人群 | 推荐模块组合 | 说明 |
|---|---|---|---|
| 识字启蒙台 | 3-8 岁孩子+家长 | 每日认字任务(现场写) + FLIP 象形翻卡 + SHOP 积分奖励 | 需家长/孩子双模式 Tab + 4 位密码；字体放大、按钮 ≥50px、配色鲜艳 |
| 习惯打卡台 | 泛用户 | MATRIX 多习惯矩阵 + HEAT 连续热力图 + RING 今日完成度 | 连续天数是最强激励，务必展示 streak |
| 记账理财台 | 泛用户 | 收支录入(现场写) + PIE 分类占比 + TREND 月度趋势 | 支出红收入绿；月预算进度条；导出 CSV |
| 健身减脂台 | 泛用户 | 体重记录+TREND 折线 + 运动打卡 MATRIX + 食谱清单(现场写) | 体重下降方向展示要正向 |
| 学习备考台 | 学生/备考党 | 刷题计数+RING 正确率 + 错题本(现场写) + 倒计时(现场写) | 分科目统计；倒计时放大数字 |
| 职场效率台 | 职场人 | 待办清单(现场写, P0/P1/P2) + 周报汇总(现场写) + 数据卡片(现场写) | 今日要处理区直接承接待办 |
| 项目管理台 | 职场人 | 看板(现场写: 待办/进行中/已完成) + 里程碑 RING + 会议纪要(现场写) | 看板列窄屏横滑 |
| 自媒体创作台 | 自媒体人 | 选题看板(现场写) + 素材库(现场写) + 各平台数据 TREND | 灵感→写作中→已发布三列看板 |
| 阅读管理台 | 泛用户 | 书单(现场写) + 阅读进度 RING + 摘录笔记(现场写) | 按在读/读完分组 |
| 求职进度台 | 求职者 | 投递记录表(现场写) + 各阶段漏斗(现场写) + 今日要处理承接面试提醒 | 面试前自动置顶提醒 |
| 育儿成长台 | 家长 | 身高体重 TREND + 里程碑事件(现场写) + 疫苗/检查提醒(今日区承接) | 双模式可选 |
| 生活全能台 | 泛用户 | 习惯 MATRIX + 记账精简版(现场写) + 日程待办(现场写) | 3 模块混合场景，各做精简版 |

## 场景不在表内时的推导法

1. 明确目标人群与使用频率（每日打开 > 每周打开）。
2. 找出"核心动作"（记录一件事 / 完成一件事 / 学一件事），为它做最顺手的录入交互。
3. 加一个"激励闭环"模块（streak、积分、进度、对比趋势四选一）。
4. 最后检查：今日要处理区能否自动承接该场景的时效性事项？不能则现场补一个提醒数据源。
